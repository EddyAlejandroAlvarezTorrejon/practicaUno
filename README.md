# Página Web HTML

Este repositorio contiene una página web simple compuesta por 5 archivos HTML:

- `index.html`: Página de inicio
- `about.html`: Acerca de la empresa
- `contact.html`: Formulario de contacto
- `services.html`: Servicios ofrecidos
- `gallery.html`: Galería de imágenes

## Requisitos del proyecto

- Usar Git con al menos 10 commits.
- Subir a GitHub en tres ramas: `main`, `develop`, y `feature`.
- Clonar el repositorio vía SSH.
- Compartir con el usuario `@juancervantesa`.

Desarrollado para fines académicos.
